# Victory Park (Ереван): прототип сайта

Демонстрационный прототип сайта парка аттракционов Victory Park (Парк Победы, Ереван): первый экран с хитами и сердечками, выбор «кто идёт», «Ваш день», заказ, демо-оплата и демо-билет с QR.

Открыть: https://konstantinpopov89.github.io/victory-park-scratch-demo/ru/ (English: `/en/`, Հայերեն: `/hy/`).

**Это не официальный сайт парка.** Цены, пакеты, статусы аттракционов, счётчики реакций и оплата демонстрационные: деньги не списываются, демо-билет на входе не действует. Действия на странице хранятся только в браузере гостя, на сервер ничего не отправляется.

Сборка: victory-scratch-prototype r05, 20.11.2026.
